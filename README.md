# LifeCompanion

An AI-assisted wellbeing companion designed to help people experiencing
loneliness, emotional distress, isolation, and difficulty maintaining
healthy routines.

## Vision

Help people move from:

"I can't handle today."

to:

"I managed today. I can handle tomorrow."

## Planned Features

- AI emotional companion
- Daily emotional check-ins
- Personal journaling
- Personalized micro-activities
- Habit and routine tracking
- Wellbeing progress dashboard
- Social reconnection
- Safety and crisis-support mechanisms

## Tech Stack

- Frontend: React
- Backend: Java + Spring Boot
- Database: MySQL
- Authentication: Spring Security + JWT
- AI: LLM API
- Deployment: TBD
